FACKTS AFRICA WEBSITE — HOMEPAGE IMAGE QUALITY AUDIT
Date: 2026-08-29

SCOPE
Homepage only. The existing layout and media hierarchy were retained.

WHAT CHANGED
• Major homepage source assets were rebuilt from the highest-resolution originals available.
• Large homepage visuals now use 3000px-wide source WebP files where the originals support it.
• No low-resolution image is upscaled to create these 3000px assets.
• The first large Archive story previously relied on a 1500px-wide source; it now uses a 3000px-wide court archive source.
• Next.js image delivery is configured for responsive AVIF/WebP output, including high-density desktop widths up to 2880px.
• Major homepage <Image> components use quality=90 and explicit sizes rules for desktop/tablet/mobile.
• object-fit: cover is retained to preserve aspect ratio; crop positions are tuned per major section.
• Presentation-time zoom was reduced so images are not unnecessarily softened by CSS scaling.
• Heavy filters were removed/reduced on the hero and brand imagery.
• Editorial frames, subtle radii, restrained overlays and shadows remain so images feel deliberate rather than raw.
